현장 관리
Firebase 연결 (Realtime Database)

연결 시 처리계획·현장·분석이 실시간 동기화됩니다. 미연결 시 localStorage에 자동 저장됩니다 (이 브라우저 한정).

AI 분석 (Gemini API)

무료 키는 Google AI Studio에서 발급. API 키는 브라우저 localStorage에만 저장됩니다.

정적 빌드 내보내기

현재 업로드된 모든 현장 데이터를 HTML에 포함시켜 index.html로 다운로드합니다. 다운받은 파일을 깃헙에 푸시하면 다른 사용자들이 페이지 접속 시 데이터를 즉시 볼 수 있습니다.
• 압축된 데이터가 HTML에 embed되어 파일 크기는 약 30MB
• 처리계획·팀장 의견·AI 분석은 Firebase로 별도 실시간 공유
• 다른 사용자는 새 빌드를 받으면 자동 갱신
